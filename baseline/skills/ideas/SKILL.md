# Ideas

An idea file records a picture as it actually arrived, in the words it
arrived in, before any formalization. It is not a claim and is not read as
one.

## What it is for

The first formalization of an intuition is usually wrong, and once it
exists the original picture is unrecoverable: the vocabulary of the
formalization overwrites it. The idea file is the copy that survives that.
When a frame is discarded, work restarts from the idea file.

## Does not apply

Citation, honesty verbs, reduction to any known form. An idea file may say
"is exactly like." It describes a picture; it does not assert a result.
Reserved words still do not appear.

## Does apply

- **Verbatim.** The user's words as given: not translated into domain
  vocabulary, not tidied. Paraphrase destroys the artifact.
- **Dated and frozen.** A changed picture is a new dated section appended
  below; the earlier one stays unedited.
- **Claude's additions marked.** Anything Claude adds -- a question, an
  extension, a pointer -- goes below a rule under `Agent notes`. If Claude
  already supplied a technical term in conversation, that is noted there.
- **Small.** One picture per section. Numbers belong in a run, outcomes in
  the journal.

## File shape

```
# <slug>

## YYYY-MM-DD

<the picture, verbatim>

---

### Agent notes

<questions, extensions marked [CONJECTURE], contamination warnings>
```

## Leaving the idea file

An idea is taken up when work is built on it, and that work names the idea
file and the dated section it was built on. The idea file is not moved or
edited; it stays as the record of the picture before a frame was chosen.
